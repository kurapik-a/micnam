## 📖 项目简介

MicNam Chassis 是一套**分布式伺服驱动的四轮麦克纳姆轮全向移动底盘**：

- **轮端**：每个轮子由一块独立的 FOC 伺服驱动板控制，具备完整的磁场定向控制能力（电流环 / 速度环 / 位置环），对外只暴露一套 CAN 寄存器接口——写目标转速、读实际转速，像一个"网络化的智能执行器"；
- **主控**：运行 FreeRTOS，通过 CAN 总线调度 4 个轮端节点，接收蓝牙遥控指令，实时完成麦克纳姆轮运动学逆解，将底盘三自由度速度 (Vx, Vy, ω) 分解为四轮目标转速；
- **能力**：零转弯半径自旋、纯横向平移、斜航复合运动，全向自由移动。

> 本仓库由轮腿机器人电控系统改造而来：轮端驱动核保留其完整 FOC 框架，主控重构为麦轮底盘调度架构，命名与协议层全部统一为底盘语义。

## ✨ 特性

- 🔬 **完整 FOC 链路**（轮端）：七段式 SVPWM · Clarke/Park 变换 · 电流环—速度环—位置环级联 PID
- 📡 **寄存器式 CAN 协议**：每节点 45 个寄存器，数据帧带校验和写入、远程帧按需回读，支持广播急停
- 🛡 **双保险失效保护**：主控心跳超时停机 + 轮端通信超时自动安全关断
- 🧮 **麦轮运动学逆解**：三自由度指令实时分解四轮转速，含轮向补偿与指令斜坡平滑
- 📶 **卡尔曼滤波测速**：一维卡尔曼抑制编码器低速量化噪声，改善速度环抖振
- ⚙️ **电机参数自辨识**：D 轴直流注入测相电阻、方波注入测电感，支撑电流环参数整定
- 🧵 **FreeRTOS 分任务调度**：通信 / 解算 / 监控按周期分层，`vTaskDelayUntil` 精确节拍
- 🐛 **VOFA+ 实时调试**：JustFloat 协议输出 10 通道内部状态，上位机直接观波形

| 部件  | 选型                              | 说明                                   |
| --- | ------------------------------- | ------------------------------------ |
| 电机  | **5010 云台无刷电机 · 360KV · 7 极对数** | 低 KV 直驱方案，转矩密度高，FOC 电流环直控转矩，12V 母线匹配 |

## 📡 CAN 协议详解

**物理层**：500 kbps · 标准帧 · 一主多从（主控唯一发起方）

### 1️⃣ 写寄存器（主控 → 轮端，6 字节数据帧）

```
┌──────────┬────────────────────────┬──────────┐
│ 字节0     │ 字节1~4                │ 字节5     │
│ 寄存器地址 │ float 值（4B 小端）      │ 校验和    │
└──────────┴────────────────────────┴──────────┘
校验和 = 字节0~4 累加 & 0xFF
CAN ID = 目标节点 ID（1~4）
```

### 2️⃣ 读寄存器（主控 → 轮端，远程帧）

主控发送 RTR=1 的远程帧，节点在中断中自动回填 **8 字节定长应答**：

```
┌────────────────────┬────────────────────┐
│ float 测量转速       │ float 测量位置      │
│ (卡尔曼滤波后 rad/s) │ (多圈机械角 rad)     │
└────────────────────┴────────────────────┘
CAN ID = 被请求节点 ID
```

### 3️⃣ 常用寄存器（每节点 45 个，摘选）

| 地址        | 名称                    | 读/写 | 说明                                       |
| --------- | --------------------- | --- | ---------------------------------------- |
| 0x02      | `REG_addr`            | W   | 节点 ID（NVR 掉电保存）                          |
| 0x08      | `REG_Output_speed`    | W   | **目标转速**（速度模式指令入口）                       |
| 0x07      | `REG_Output_currentQ` | W   | 目标 q 轴电流（力矩模式）                           |
| 0x0B      | `REG_Actual_redS`     | R   | 测量转速（卡尔曼滤波后）                             |
| 0x0C      | `REG_Actual_POS`      | R   | 测量多圈机械角                                  |
| 0x0D      | `REG_ERR`             | R   | 故障码（过压/过流/过温/超时…）                        |
| 0x1A      | `REG_MOTO_MODE`       | W   | 模式码：电流环 17308 / 速度+电流 17340 / 刹车 21376 … |
| 0x1A+7    | `REG_Overtime`        | W   | 通信超时 ms（超时自动安全关断）                        |
| 0x1F~0x22 | `REG_LOOP_*`          | W   | 电流环/速度环/位置环 PID 在线整定                     |
| 0x15      | `REG_save`            | W   | 参数写入 NVR 保存                              |

### 4️⃣ 节点 ID 配置

轮端驱动板串口发一条文本命令即可（NVR 掉电保存）：

```
StrinW1;2;1     ← 把本板 ID 设为 1（左前轮），其余板依次 2/3/4
```

### 麦轮运动学逆解

```
ω_LF = ( Vx − Vy − (lx+ly)·ω ) / r        ω_RF = ( Vx + Vy + (lx+ly)·ω ) / r
ω_LB = ( Vx + Vy − (lx+ly)·ω ) / r        ω_RB = ( Vx − Vy + (lx+ly)·ω ) / r

Vx: 纵向速度 (向前+)   Vy: 横向速度 (向左+)   ω: 自转角速度 (逆时针+)
lx/ly: 轮到底盘中心半距   r: 轮半径   ω_x: 各轮转速
```

## 🚀 快速开始

### 环境准备

| 工具         | 版本/要求                                           |
| ---------- | ----------------------------------------------- |
| Keil MDK 5 | AC5 编译器（V5.06）                                  |
| 器件包        | `Linko.LKS45x`（凌鸥官网 Device Pack 页）+ AT32F435 系列 |
| 调试器        | AT-Link（主控）/ J-Link（轮端）                         |
| 上位机        | VOFA+（JustFloat 协议）                             |

### 编译 & 烧录

```bash
# 命令行编译（或 Keil IDE 打开对应 uvprojx）
UV4.exe -r micnam_master/mdk_v5/communication_mode.uvprojx -j0 -o build.log
UV4.exe -r micnam_wheel/lks_45_project.uvprojx      -j0 -o build.log
````

### 上电配置流程

```
1. 烧录轮端固件 → 串口发 StrinW1;2;X 依次配置 4 块板 ID 为 1/2/3/4
2. 电角度标定：主控帧字节20 组合键广播，或逐板串口触发
3. 接 CAN 总线（CANH/CANL 对接 + 两端 120Ω）
4. 主控上电：constant_init 自动复位节点 + 配置速度电流模式 + 超时 200ms
5. 蓝牙连接 → 按键 0x10 启动 → 摇杆控车
```

### 标定清单（首车上路必做）

- [ ] `mecanum.h`：轮半径 / 半轴距实测值
- [ ] `mecanum.c`：`wheel_dir_comp[4]` 四轮转向逐轮标定
- [ ] 遥控通道方向确认（摇杆向前 = Vx 为正）
